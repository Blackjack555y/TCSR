Informe parcial: una fuente no respondió. El informe se entrega igual, con esa verificación como "No disponible".

Cómo se hace la cuenta
  1. ¿Hay al menos una alerta? → Atención prioritaria
  2. Si no: ¿hay algo que requiere revisión? → Revisión recomendada
  3. Si no: ¿hay algo no disponible? → Revisión completada con observaciones
  4. Si no: → Sin alertas relevantes

Por qué no es un puntaje

El semáforo no suma puntos: manda el peor resultado. Una sola alerta (por ejemplo, un embargo) basta para "Atención prioritaria", aunque todo lo demás esté limpio, porque un puntaje promedio podría esconderla. Los conteos solo sirven para decir cuántos aspectos requieren atención. Y como "No disponible" significa que no tuvimos el dato, nunca deja concluir "Sin alertas relevantes". El sistema tampoco concluye nunca "listo para traspaso" ni "compra recomendada".

Qué verificaciones incluye cada informe

Lo que un informe no incluye aparece como "No disponible", nunca se omite. Por eso el Básico y el Por VIN nunca pueden llegar a "Sin alertas relevantes".
